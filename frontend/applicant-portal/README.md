# Applicant Portal

The applicant portal is the public-facing surface for the Sri Lanka tourist visa PoC and is aligned with [frontend/FRONTEND_IMPLEMENTATION_PLAN.md](/D:/PROJECTS/Startup/VisaAgent/VisaProcessAutomation/frontend/FRONTEND_IMPLEMENTATION_PLAN.md).

Current scope:

- application submission
- document guidance and checklist visibility
- case status lookup
- applicant timeline and notices
- plain-language next-step messaging
- direct file upload
- extension request initiation
- extension status visibility

Frontend priorities:

- clear case state and current holder visibility
- reduced confusion during document and manual-review loops
- clear explanation that ETA or recommendation states are not final legal decisions
- responsive, high-trust presentation suitable for a government workflow PoC
- Tailwind-based MVP UI without a separate frontend build step yet
