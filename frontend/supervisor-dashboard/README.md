# Supervisor Dashboard

The supervisor dashboard is the operations surface for queue visibility and workflow pressure across the Sri Lanka tourist-visit process.

Current scope:

- queue summary retrieval
- counts by workflow state
- manual referral visibility
- document-loop and officer-review bottleneck framing

Frontend priorities:

- make operational pressure visible quickly
- support queue triage without flattening legal decision ownership
- Tailwind-based MVP UI without a separate frontend build step yet
